# KÖNIG — CASE 01

Status: em construção
Owner: Hianto
Orquestração: Doug / Squad Master
Base operacional: KonigcomCRM

## Objetivo

Usar a própria König como primeiro cliente do sistema. O CRM deixa de ser apenas infraestrutura comercial e passa a representar a operação real da empresa: aquisição, vendas, entrega, expansão e LTV.

## Fluxo comercial oficial

Prospecção -> Raio-X assíncrono -> Demonstração -> WhatsApp -> Proposta -> Fechamento -> Onboarding -> Entrega -> Expansion Review -> Upsell/Cross-sell -> Retenção.

Calls não são etapa padrão. Entram apenas quando:
- contrato é grande;
- existe objeção relevante;
- existem múltiplos decisores;
- o cliente pede.

## Escada de valor

1. Entrada: Raio-X / auditoria assíncrona
2. Core: Revenue Autopilot
3. Expansão: Growth Autopilot
4. Expansão: Operations Autopilot
5. Expansão: Web & Conversion
6. Expansão: Software / sistemas
7. Premium: AI Operating System

## Autopilots

### Revenue Autopilot
Captura lead, responde, qualifica, registra no CRM, faz follow-up, gera proposta, agenda, reativa lead, acompanha pipeline e sinaliza oportunidades quentes.

### Growth Autopilot
Pesquisa mercado, acompanha concorrência, sugere campanhas, identifica gargalos, gera experimentos, acompanha métricas e propõe crescimento.

### Operations Autopilot
Executa rotinas administrativas, movimenta dados, dispara workflows, gera relatórios e opera sistemas integrados.

### Web Conversion Autopilot
Audita site, cria e atualiza páginas, executa SEO/AEO/GEO, monitora CRO e performance.

## Regra de produto

O cliente não compra agente, skill, MCP ou n8n. Esses são componentes internos.

O cliente compra uma operação pronta para atingir um resultado de negócio.
